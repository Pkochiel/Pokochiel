# TEST - Web - AI時代のコンサルタントの役割変化

## 引用・要約メモ

### リサーチ自動化
市場調査・競合調査・事例収集といった、従来ジュニアコンサルタントが
数日かけていた作業が数時間に短縮された。文献レビューや公開情報の整理は
ほぼAIに置き換わりつつある。
記事の主張：「リサーチが速くなったこと自体は差別化にならない。
全員が同じ速度を手に入れるから」。

### 仮説構築
一方で、**何を調べるべきかを決める工程**はAIに任せきれていない。
AIは与えられた問いには強いが、
「そもそもクライアントの本当の課題は何か」を設定する部分は人間が担っている。
記事はここを「問いの設計」と呼び、今後のコンサルタントの中核能力と位置づける。

### AIによる資料作成
スライドのドラフト生成、グラフ作成、文章の推敲はAIが実用水準。
ただし出来上がるのは「一般的に正しいが、そのクライアントに刺さらない」資料。
文脈固有の重みづけは人間が入れる必要がある。

### 人間の判断
複数の選択肢が出そろった後、どれを選ぶかは
「クライアント組織が何を受け入れられるか」に依存する。
これは公開情報に載っておらず、AIには推論できない。
記事の表現：「意思決定に必要な情報の大半は、文書化されていない」。

### クライアントコミュニケーション
信頼関係の構築、悪い知らせの伝え方、組織内の政治的力学の読み。
記事はこれを「AIが最も代替しにくい領域」としている。
提案の内容が正しくても、伝え方を誤ると通らない。

## 記事の結論
コンサルタントの価値は「作業を速くこなす能力」から
「問いを立て、判断し、納得させる能力」へ移行する。
作業能力を売っていた層は淘汰される。
