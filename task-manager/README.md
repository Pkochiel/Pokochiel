# 予定 — タスク管理アプリ（PWA）

iPad / iPhone のホーム画面に追加して、ネイティブアプリのように使えるタスク管理アプリです。
リスト表示とタイムライン表示を切り替えられ、データは端末内（localStorage）に保存されるため、
オフラインでも動作します。

## 構成ファイル

| ファイル | 役割 |
|----------|------|
| `index.html` | アプリ本体（UI + ロジック） |
| `manifest.json` | アプリ名・アイコン・全画面表示などのPWA設定 |
| `service-worker.js` | オフライン動作のためのキャッシュ |
| `icons/` | ホーム画面・スプラッシュ用アイコン（PNG） |
| `make_icons.py` | アイコン再生成スクリプト（Pillowが必要） |

---

## 公開方法（GitHub Pages・無料）

PWA は HTTPS 配信が必要です。GitHub Pages を使うと無料で配信できます。

1. GitHub でこのリポジトリを開く
2. **Settings** → **Pages** を開く
3. **Build and deployment** の **Source** を **GitHub Actions** に設定
4. 同梱の `.github/workflows/deploy-task-manager.yml` が自動で実行され、公開されます
5. 数分後、Pages の画面に表示される URL が公開アドレスです
   （例: `https://<ユーザー名>.github.io/<リポジトリ名>/`）

> 手動で行う場合は Source を「Deploy from a branch」にし、ブランチと
> `/task-manager`（または対象フォルダ）を選んでも公開できます。

## iPhone / iPad でアプリとして使う手順

1. **Safari** で公開URLを開く（※ChromeなどではなくSafariが必要）
2. 画面下（iPadは右上）の **共有ボタン**（□から↑が出ているアイコン）をタップ
3. メニューから **「ホーム画面に追加」** を選ぶ
4. 名前を確認して **「追加」** をタップ
5. ホーム画面に「予定」アイコンが追加され、タップすると全画面アプリとして起動します

これで、アドレスバーのない単独アプリのように使えます。オフラインでも起動できます。

---

## 使い方

- **追加**: 上部の入力欄にやることを入れて「＋」。必要なら開始/終了時刻も設定
- **完了**: 左の丸をタップ
- **削除**: 右の「×」をタップ
- **時刻の変更**: タスクを長押し（約0.5秒）すると時間編集ダイアログが開きます
- **表示切替**: 「リスト」「タイムライン」を切替
- **日付移動**: ヘッダーの「‹ 今日 ›」で前後の日へ移動

---

## アイコンを作り直す

デザインを変えたい場合は、`make_icons.py` 内の色や形を編集して再生成します。

```bash
pip install Pillow
python3 make_icons.py
```

`service-worker.js` の `CACHE` のバージョン名（例: `yotei-v1` → `yotei-v2`）を
更新してから再公開すると、端末側のキャッシュが確実に更新されます。
