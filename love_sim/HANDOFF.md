#### 透過処理メモ
- この環境では rembg のモデルDLがネットワーク制限で失敗した
- **白背景で生成されていれば Pillow の色域ベース白抜きで透過可能**：
```python
from PIL import Image
import numpy as np
img = Image.open('input.png').convert('RGBA')
a = np.array(img)
# 白に近いピクセル(R,G,B>240)を透明化
mask = (a[:,:,0]>240)&(a[:,:,1]>240)&(a[:,:,2]>240)
a[mask,3] = 0
Image.fromarray(a).save('assets/chara/ayaka_normal.png')
```
- 髪の輪郭など白縁が残る場合はしきい値や縁処理を調整
- Claude Code環境でネット制限がなければ rembg / 生成AIの透過機能を使ってもよい
