# 『恋愛☆大作戦！ 〜となりの席は天敵だった件〜』 ゲームバイブル

> 本ドキュメントは開発中ずっと参照する「世界観・キャラ・システムの正典（バイブル）」です。
> シナリオを書くとき・分岐を増やすときは必ずここと整合を取ること。
> Claude Codeへの指示例：「bible.md の神崎彩花ルートに沿って、第3話のスクリプトを scripts 配列に追記して」

---

## 0. 一言コンセプト

**「ドタバタ青春ラブコメの皮を被った、ちゃんと泣ける物語」**

- 基本トーン：スクールランブル的なギャグ・テンポ・勘違い・全力ツッコミ
- 要所の刺し方：アマガミのように一人ひとりと深く向き合い、各ルート終盤で「この子の本当の弱さ・願い」に触れて感動させる
- システム骨格：ときメモ式の育成（毎日の行動でパラメータと好感度を育てる）＋フラグ管理で個別ルートへ分岐

## 1. 世界観・舞台設定

### 1-1. 舞台

| 項目 | 設定 |
|------|------|
| 学校名 | 私立 桜ヶ丘学園（さくらがおか） |
| 所在地 | 海と山に挟まれた地方都市。坂が多く、夏は蝉、冬は澄んだ空気 |
| 時代 | 現代（スマホあり。ただしレトロな商店街や古い校舎も残る） |
| 学年 | 主人公は2年生。物語は4月〜翌3月の1年間 |
| 校風 | 自由でちょっとゆるい。変な部活・変な教師が多く、毎日が騒がしい |

### 1-2. 主要ロケーション

- **2年A組 教室** — 物語の起点。主人公と彩花は隣の席
- **屋上** — 感動シーン・本音を語る場所の定番
- **旧校舎/図書室** — 静かな時間、凛桜の秘密に関わる
- **商店街・駄菓子屋「みかど」** — 放課後のたまり場。名物おばあちゃん
- **海辺の堤防** — 夏の決定的シーン用
- **学園祭の中庭ステージ** — 中盤の山場（全ヒロイン共通の大イベント）

### 1-3. 1年間のイベントカレンダー（全ルート共通の幹）

| 時期 | 共通イベント | 役割 |
|------|------------|------|
| 4月 | 始業・席替え | 物語の発端。誰の隣になるかで序盤が変わる |
| 5月 | 中間テスト | パラメータ（文化力）の試練。順位が出る |
| 6月 | 梅雨・体育祭 | 体力パラメータの見せ場。雨の相合傘イベントも |
| 7-8月 | 夏休み・海・夏祭り | **関係が大きく動く季節**。各ヒロインの夏イベント |

| 10-11月 | 文化的な季節・修学旅行 | 距離が一気に縮まる。ルート確定が近づく |
| 12月 | クリスマス・期末 | 告白イベントの定番ポイント |
| 1-2月 | バレンタイン | 両想い確認・すれ違い |

## 2. パラメータ・システム設計（ときメモ式）

### 2-1. 育成パラメータ（4種）

| パラメータ | 表示 | 意味 | 主に効くヒロイン |
|-----------|------|------|----------------|
| 文化力 | 📚 | 学力・教養・芸術センス | 凛桜（知的な会話が刺さる） |
| 体力 | ⚡ | 運動・スタミナ・行動力 | 第3ヒロイン（運動部想定） |
| 友情 | 🤝 | コミュ力・人望・場の空気 | 健二・サブイベント全般 |
| 好感度 | 💗 | ヒロイン個別の好感度（キャラごとに別管理） | 全員（最重要） |

> 注意：好感度は **ヒロインごとに独立した数値** で持つこと（`affection.ayaka`, `affection.rio` のように）。
> 表示バーの「💗」は「現在フォーカスしているヒロイン」または「最も高い好感度」を表示する。

### 2-2. 行動システム（カレンダー画面）

毎日（または毎週）、プレイヤーは行動を1つ選ぶ：

| 行動 | 上昇パラメータ | コメディ的フレーバー |
|------|--------------|---------------------|
| デートに誘う | 好感度 ++ | 勇気を出すが断られると赤っ恥 |
| みんなで遊ぶ | 友情 ++ / 好感度 + | 気づくと全員集合してカオス |
| 図書館で勉強 | 文化力 ++ | なぜか彩花も来て静かじゃない |
| 部活で根性 | 体力 ++ | 監督の「もう一本！」が止まらない |

### 2-3. 好感度のしきい値とルート分岐（アマガミ式）

```
好感度レベル：
  0-19   他人ゾーン     … 普通の会話。素っ気ない
  20-39  クラスメイト   … 軽口を言い合える
  40-59  気になる存在   … 個別イベントが解禁され始める
  60-79  両想い手前     … ドキドキイベント・嫉妬イベント
  80-100 相思相愛       … 個別ルート＆告白イベントが発火
```

- **ルート確定条件**：9月の学園祭時点で好感度40以上のヒロインが「攻略候補」になる
- **個別ルート突入**：12月までに特定ヒロインの好感度を80以上にし、かつ「個別フラグ」を立てる
- **トゥルーエンド条件**：個別ルート中の重要選択を全て正解＋隠しフラグ（後述）

## 3. キャラクター設定

### 3-1. 神崎 彩花（かんざき あやか）｜メインヒロイン

> **ビジュアル確定**：明るいオレンジ系の髪をポニーテール、人懐っこい大きな笑顔、野球ユニフォーム。
> 元気いっぱいで、剛速球を投げる。決め台詞は「愛の剛速球、キャッチできる？」（→ art/prompts.md 参照）

| 項目 | 設定 |
|------|------|
| 立ち位置 | 幼馴染・隣の席・野球部のエース |
| 属性 | 天真爛漫・パワー系・ちょっと天然。負けず嫌いで真っ直ぐ |
| 一人称 | 「あたし」 |
| 口調 | 「〜だよっ！」「よーし、いっくよー！」勢いがあって裏表がない。照れると急に挙動不審 |
| 好きなもの | 野球、甘いもの（特にプリン）、勝負ごと全般 |
| 苦手なもの | じっとしていること、難しい話、自分の気持ちを言葉にすること |
| 表面の性格 | 全力でまっすぐ。場を明るくする太陽みたいな子。距離感が近い |
| **本当の弱さ** | 「ずっと一緒にいた相手だからこそ、"特別"だと踏み込めない」。幼馴染の心地よさを壊すのが怖い。明るさの裏で、自分の気持ちにだけは鈍感なふりをしている |
| ルートのテーマ | **まっすぐなのに恋にだけ不器用な少女が、勝負から逃げずに本当の気持ちを投げ込む** |
| クライマックス | 最後の夏の大会・引退の日。マウンドで、人生で一番大事な"剛速球"を主人公に投げる |

**コメディの見せ場**：勢い余って物理的にやらかす（剛速球で何かを破壊）／恋愛の話になると急にポンコツ化
**感動の見せ場**：いつも全力な子が、声を震わせて初めて弱音を吐く瞬間。「あたし、本当は……」

### 3-2. 壇ノ浦 凛桜（だんのうら りお）｜謎の転校生ヒロイン

| 項目 | 設定 |
|------|------|
| 立ち位置 | 突然現れた転校生。主人公を「観察対象」と呼ぶ |
| 属性 | クーデレ／不思議ちゃん。銀髪・オッドアイ（片目が金色） |
| 一人称 | 「私」 |
| 口調 | 丁寧で淡々。たまに核心を突く。「ふふ」が口癖 |
| 好きなもの | 観察、紅茶、古い本、人の心の動き |
| 秘密 | （要設計）なぜ主人公を観察するのか。家庭の事情／過去の約束など |
| 表面の性格 | 何を考えているか読めない。マイペースで周囲を振り回す |
| **本当の弱さ** | 人との距離の取り方を知らない。「観察」でしか人と関われなかった孤独 |
| ルートのテーマ | **観察者だった少女が、初めて当事者として誰かを好きになる** |
| クライマックス | 凛桜が転校でまた去ろうとする／秘密が明かされる場面 |

**コメディの見せ場**：天然な行動で場をかき乱す／彩花と謎の対抗心
**感動の見せ場**：初めて自分から手を伸ばす瞬間

### 3-3. 早瀬 すず（はやせ すず）｜第3ヒロイン・サッカー少女

> **ビジュアル確定**：黒髪ショートボブ、元気な笑顔、サッカーユニフォーム。河川敷でリフティング。
> ノリが良くテンポが速い。決め台詞「『ボール』がヤキモチ焼いてるから、あっち行って！」（→ art/prompts.md 参照）

| 項目 | 設定 |
|------|------|
| 立ち位置 | 別クラス／サッカー部。主人公とは部活の朝練で知り合う |
| 属性 | 明朗快活・ボケもツッコミもいける・ノリ重視 |
| 一人称 | 「うち」または「あたし」 |
| 口調 | 「〜っしょ！」「ナイスナイス！」テンポが速く、人をいじって笑わせる |
| 好きなもの | サッカー、river side（河川敷）でのリフティング、人を笑わせること |
| 苦手なもの | しんみりした空気、本気の告白（茶化して逃げてしまう） |
| 表面の性格 | 誰とでもすぐ仲良くなるムードメーカー。恋愛もネタにして軽く流す |
| **本当の弱さ** | 「軽さ」で本心を隠している。本当は誰よりも傷つきやすく、好きな相手の前ほどふざけてしまう |
| ルートのテーマ | **いつも笑ってごまかす子が、初めて"茶化さずに"気持ちを口にする** |
| 育成パラメータ | **体力（⚡）が効く**。スポーツ系イベントで好感度が伸びる |

**コメディの見せ場**：何でもサッカーに例える／ボールに表情があるかのように扱う（ヤキモチ焼くボール）
**感動の見せ場**：試合に負けた夜、初めて笑わずに泣く。「……うち、ずっとふざけてないと、こわいんだ」

> 採用メモ：彩花（野球）とすず（サッカー）でスポーツ系2人になるが、
> 彩花＝幼馴染の重さ／すず＝距離が近いのに本心が遠い、で役割が被らないよう設計済み。
> もしすずを使わない場合は、この枠を文化系（凛桜）に寄せてもよい。

### 3-4. 田中 健二（たなか けんじ）｜親友・サブ

|------|------|

## 4. シナリオ構成のルール

### 4-1. 1話の基本構造（スクールランブル式テンポ）

```
① つかみ      … 日常 or ギャグから入る（重く始めない）
② 事件        … 勘違い・ハプニング・誰かの乱入
③ ドタバタ    … 巻き込まれてカオスに（選択肢①）
④ 小さな本音  … 騒ぎの中でふと漏れるヒロインの素顔
⑤ 引き        … 次回への期待 or じんわり余韻（選択肢②）
```

### 4-2. 感動を効かせる原則（アマガミ式）

1. **笑いの落差で泣かせる** — 普段ふざけているキャラほど、真剣な瞬間が刺さる
2. **本音は終盤まで隠す** — 各キャラの「本当の弱さ」(3章)は個別ルート終盤で初めて明かす
3. **選択肢に意味を持たせる** — 単なる好感度増減でなく、後の展開で回収する
4. **共通体験を作る** — 序盤の何気ない約束・小物・口癖を、終盤で回収して泣かせる

### 4-3. スクリプトのデータ構造（実装と対応）

各シーンは `scripts` 配列のオブジェクト。型は以下：

```js
// ナレーション
{ type:'narration', bg:'classroom', text:'…' }

// セリフ
{ type:'dialogue', speaker:'ayaka', expr:'angry', char2:'kenji', text:'…' }

// 選択肢（好感度・フラグを操作）
{ type:'choice', choices:[
  { text:'選択肢文', effect:{ ayaka:+18, friend:+5 }, flag:'ayaka_hairpin', next:8 },
] }

// 分岐先指定（合流など）
{ ..., gotoAfter: 12 }

// 話の終端
{ ..., isEnd: true }
```

- `speaker` / `char2` は `CHARS` のキー（ayaka, kenji, rio, …）
- `expr` は表情（normal / angry / shy / surprised / smile / laugh など）
- `effect` のキーは好感度（キャラ名）または育成パラメータ（friend/culture/sport）
- `flag` を立てると後の分岐条件に使える

## 5. フラグ設計（個別ルートの鍵）

| フラグ名 | 立つ条件 | 効果 |
|---------|---------|------|
| `ayaka_childhood` | 第1話で幼馴染エピソードを選択 | 彩花ルート開放の前提 |
| `ayaka_hairpin` | ヘアピンを褒める選択 | 彩花の照れイベント解禁 |
| `rio_secret_1` | 凛桜の観察メモを見てしまう | 凛桜ルートの謎フラグ |
| `festival_promise` | 学園祭で特定ヒロインと約束 | 終盤の回収イベント |
| `true_route` | 各ルートの重要選択を全正解 | トゥルーエンド解禁 |

> 実装上は `state.flags = { ayaka_hairpin: true, ... }` のオブジェクトで管理する。

## 6. 開発の進め方（Claude Codeでの作業単位）

おすすめの粒度で1つずつ依頼すると破綻しにくい：

1. 「bible.md の第3-3を埋めて、第3ヒロインを設計して」
2. 「神崎彩花ルートの第2話を scripts 配列に追記。4-1の構造と3-1の設定に従って」
3. 「好感度をキャラ別に持つよう state を改修して、バーをフォーカス制御に」
4. 「フラグ管理（第5章）を実装。学園祭イベントで分岐するように」
5. 「localStorage でセーブ/ロード。複数スロット対応」
6. 「BGMを場面ごとに切り替え（日常/ときめき/感動/コメディ）」
7. 「立ち絵をブラッシュアップ。表情差分を増やす」

## 7. アートの方向性（アマガミ級を目指す指針）

現状はCSS/SVGの簡易立ち絵。完成度を上げる選択肢：

- **短期**：SVGの描き込みを増やす（陰影・髪のハイライト・衣装ディテール）
- **中期**：外部の立ち絵を画像（PNG）で差し込む構造に変更し、表情差分を画像で管理
- **長期**：プロ絵師に発注 or 画像生成で立ち絵・イベントCGを制作し、`assets/` で管理

> 実装をPNG差し込み式にしておくと、後からアートだけ差し替えられる。
> Claude Codeに「立ち絵をSVG直書きから assets/chara/*.png 読み込み式にリファクタして」と頼める。
